# PersonaliCraft Creations

Crea una app web llamada PersonaliCraft, un e-commerce de productos personalizados (vinil textil, vinil decorativo, etiquetas escolares, y pedidos a medida). Usa una paleta de rosas suaves y cálidos (tipo rosa pastel, nada saturado ni neón), fondo claro, diseño limpio y amigable, tipografía moderna y legible.

Genera la pantalla de inicio con:
- Un header con el logo/nombre 'PersonaliCraft' a la izquierda y un ícono de carrito a la derecha.
- Un banner de bienvenida con un texto corto tipo 'Tus ideas, hechas realidad con amor y vinil'.
- Una sección de categorías con 4 tarjetas clicables: 'Vinil Textil', 'Vinil Decorativo', 'Etiquetas Escolares', y 'Pide tu diseño a medida' — cada tarjeta debe tener un ícono o imagen representativa y un texto corto debajo.
- Que las tarjetas sean funcionales: al hacer clic deben navegar a una página de detalle (por ahora puede estar vacía o con un texto placeholder 'Próximamente', pero la navegación debe funcionar).

Estructura el proyecto para que sea fácil agregar más pantallas después (catálogo, personalización de producto, carrito, seguimiento de pedido).Usa esta imagen como referencia visual para el diseño y la distribución de elementos
